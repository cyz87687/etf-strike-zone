## 数据来源

- **腾讯财经公开行情接口**（`web.ifzq.gtimg.cn` 前复权日 K 线），与 WeStock / 腾讯自选股**同源**。
- 仅用 Python 标准库抓取与计算，无第三方依赖，可在 GitHub Actions 无依赖运行。

## 指标与方法

- MA5/10/20/30/60/120/250、RSI(2)/RSI(14)（Wilder 平滑）、BOLL(20, 2σ)、MACD(12,26,9) 均由前复权收盘价计算。
- **击球区评分 0–5**（越高越接近可介入的回调支撑位）：
  - 深度回调（距 52 周高点回撤）
  - 超卖（RSI₂ 越低越高）
  - 结构未破（仅当价格已 ≤ MA20 即确为回调时，站上 MA60/MA120 才计分）
  - 企稳（MACD 柱翻正）
  - 处于上升通道（价格 > MA20）的 ETF 不计入击球区（属趋势跟随）。

## 自动化

- GitHub Actions 工作流 `.github/workflows/update.yml`：每周一至周五 **北京时间 16:00** 运行 `generate.py`，重算后提交 `index.html`。
- 页面通过 **GitHub Pages** 发布（分支 `main`，根目录）。

## 本地运行

```bash
python generate.py      # 生成 index.html（取最近交易日数据）
```
